# Assignment 3 — Final Project

Data visualizations from the City of Toronto Open Data Portal (Toronto Public Library datasets).

## Contents
- `final_project.ipynb` — main notebook: live CKAN fetch, cleaning, both visualizations.
- `final_project_code.py` — code appendix (same logic as a runnable script).
- `viz1_visits_per_sqft.md` — written reflection for Visualization 1.
- `viz2_size_vs_visits.md` — written reflection for Visualization 2.
- `figures/` — exported 300-dpi PNGs (generated by running the notebook/script).

## Data sources
- Branch General Information: https://open.toronto.ca/dataset/library-branch-general-information/
- Visits: https://open.toronto.ca/dataset/library-visits/

## To run
```
pip install requests pandas numpy matplotlib
python final_project_code.py     # or run final_project.ipynb top to bottom
```
Requires internet access (fetches live from the City of Toronto CKAN API).
